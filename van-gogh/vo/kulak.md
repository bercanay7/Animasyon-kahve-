# Kulakla dinlenecekler (seslendirme, 27 Kasım)

Whisper (faster-whisper medium) karşılaştırmasında kuşkulu kalan yerler. Seçilen çekim → dinlenecek yer.

| Çekim | Cümle | Kuşku | Not |
|---|---|---|---|
| s01_a | B07 "Haziranda **üçüncü** kattaki bir daireye" | Whisper iki çekimde de "üç kattaki" yazdı | Enerji eğrisi "üçüncü" uzunluğunda sesli bölge gösteriyor; büyük olasılıkla Whisper hatası |
| s06_a | G05 "**zam** ister" | Whisper "zan" yazdı | Öbür çekimde (s06_b) bu yer doğru ama kanca sorusu "yeğenimi" diye çıkmış |
| s05_b | F04 "badem" | a çekiminde "baden" yazılmıştı; b seçildi | |
| s08_b | I02 "mektupları" | a çekiminde "mektutları"; b seçildi | |
| s07_a | H09 "üçte ikisi" | Whisper "üçde" | Yazım farkı olabilir |
